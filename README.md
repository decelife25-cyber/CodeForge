# CodeForge

Proyecto para desarrollar una aplicación Android de edición de repositorios GitHub.

Este repositorio contiene el MVP mínimo Android (Kotlin + Jetpack Compose + Material 3).

Cómo abrir:
1. Abrir en Android Studio
2. Seleccionar el módulo `app` y sincronizar Gradle
3. Ejecutar en un dispositivo o emulador

Nota: Este commit crea la estructura mínima del proyecto; aún no hay funcionalidades implementadas.
